## Test Classes

### 1. ValidInputTests (7 tests)

Well-formed flight configurations must produce a finite, positive predicted
fare. Verified for IndiGo (nonstop), Air India (one stop), SpiceJet, Vistara
Premium economy, and journeys in all four seasons (Winter, Summer, Monsoon,
Post-Monsoon).

### 2. MissingInputTests (11 tests)

Each of the following inputs must raise ValueError when absent or invalid:

| Input | Condition |
|---|---|
| Airline | Blank string |
| Source | Blank string |
| Destination | Blank string |
| Route | Blank string |
| Duration | Zero or negative |
| Stops | Negative integer |
| Departure hour | < 0 or >= 24 |
| Arrival hour | < 0 or >= 24 |

### 3. UnknownCategoryTests (5 tests)

Values unseen during training (new airline, route, additional-info, source,
or destination) must not raise an exception and must return a finite fare. The
model pipeline handles these via the handle_unknown="ignore" setting on the
one-hot encoder fitted in Phase 7.

### 6. BookingWindowTests (9 tests)

Journey month drives cyclical Month_Sin and Month_Cos encodings.

| Month | Month_Sin | Month_Cos |
|---:|---:|---:|
| January (1) | 0.0 | 1.0 |
| April (4) | 1.0 | ~0.0 |
| July (7) | 0.0 | -1.0 |

All 12 months produce Sin/Cos values in [−1, 1]. Season labels are verified for
all 12 months. Weekend indicator is 1 for Saturday and 0 for Monday. Both
Summer and Winter journeys return finite fares.
